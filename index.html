Chapter 1 – Problem Solving and Flowcharts

1.1 Problem solving

To make a computer solve a problem, the programmer must prepare a method and a detailed procedure. Problem solving involves:

  • Detailed study and redefinition of the problem
  • Identifying input data, output requirements, conditions and limitations
  • Finding alternative methods and selecting the most suitable one
  • Preparing a list of procedures and steps to get the solution
  • Generating the output
Algorithm: a sequence of instructions designed so that, if executed in a specific sequence, the desired result is obtained.

1.2 Flowcharts

Flowchart: a symbolic representation of a solution to a given task. It is drawn before coding, can be made for practically any job, and helps trace and detect logical errors before the program is written.

1.3 Types of flowcharts

Program flowchartSystem flowchart
Used by programmers. Shows program structure, logic flow, inputs, processing, calculations, decision conditions, branching/looping and outputs. Emphasis is on logic. Part of system documentation.Used by system analysts. Shows processes, sub-systems, outputs and operations on data in a system.

1.4 Flowchart symbols

Symbols are standardised by ANSI (American National Standards Institute). Flowcharts are independent of the programming language, so you concentrate on logic first and on coding afterwards. Boxes are joined by solid lines with arrowheads.

SymbolUse
TerminalStart and stop. Only one START and one STOP in a flowchart; a pause is also shown with it.
Input/OutputAny input (keyboard, etc.) or output (printer, monitor, disk, etc.).
ProcessArithmetic and data movement. Several processes can be in one box, top to bottom in order.
DecisionA point where a decision is made and branching follows the result. The criterion is written inside; all possible paths must be accounted for.
FlowlinesSolid lines with arrowheads showing the exact order. Normal flow is top to bottom and left to right.
ConnectorA circle with a letter or digit. Identically labelled connectors link parts of a big or multi-page flowchart. A connector is not an operation.
Rules for symbols: do not change the shape; size may change; symbol must be easily recognised; details must be legible; flowlines should not cross.

1.5 Developing flowcharts

Consider: define the problem; identify the steps; determine input and output parameters; get expected input values and output result; determine the computations and decisions.

Example – add two numbers: Start → Get N1, N2 → N1+N2 → Print result → Stop.
Greatest of two: Start → Get A, B → decision A > B? yes: print A, no: print B → Stop. Inputs of the same kind can share one box.

1.6 Techniques

Computations: create variables (memvars), read data, calculate, print. Example: Celsius to Fahrenheit (create F, C; read C; compute F; print F). Inches to centimetres works the same way.

Decision making: test the condition; true → "Yes" steps, false → "No" steps. Uses relational operators (equal/unequal) and logical operators (combine expressions). Constructs: If, If-else-endif, If-elseif-endif, Do case, Switch.

Pass/fail example: read m1, m2, m3. Pass if all marks >= 35, else fail. Alternative: one test m1>=35 and m2>=35 and m3>=35 with AND.

Loops: repeated use of steps. Fixed loop – repeated a fixed number of times. Variable loop – repeated until a condition is met, so the count can vary. A loop includes: set and initialise a counter, execute operations, test for completion, increment the counter. Loop constructs: do-while, while, for, for-next.

Sum of first N numbers: S=0, I=1 → repeat: S=S+I, I=I+1 while I <= N → print S.
Is the character Z? read C; if C is not 'Z' read again; if 'Z' print END.
The notes say "if no go to step 6" after the test I<=N; the loop returns to step 6 while I<=N is true.

Predefined process: listed as an advanced technique in the chapter summary.

Chapter 2 – Introduction to C Programming

2.1 About C

C was developed at AT&T's Bell Laboratories, USA, in 1972, designed by Dennis Ritchie. Unix was developed there at about the same time and is written almost entirely in C.
  • Robust, with a rich set of built-in functions; simple to learn and use
  • Suitable for system software, application programs and business packages
  • Lies between high-level and low-level languages
  • Highly portable: programs run on other computers with little or no change
  • Only 32 keywords; a C program is a collection of functions

2.2 First program

main()
{
  /* The First C program */
  printf("\nMy first C program");
}
  • main() is where execution begins; every program needs it. Parentheses are required.
  • { } mark the start and end of the function body.
  • /* ... */ are comments, ignored by the compiler, may span lines, may not be nested.
  • printf is a predefined function for output. \n starts a new line.
  • Every statement ends with a semicolon. Write in lowercase; uppercase is for symbolic constants.
Running a program: write it and save with .c → compile (syntax errors are reported and compilation stops) → object file .obj → link → executable .exe → run by typing its name.

2.3 Character set and tokens

Characters: letters A–Z, a–z; digits 0–9; special symbols; white spaces (blank, tab, new line, form feed, carriage return). White space cannot be placed inside keywords or identifiers.

Token: the smallest unit in a C program. Types: keywords, identifiers, constants, strings, special symbols, operators.

Keywords have fixed meanings (reserved words), cannot be used as variable names and are written in lowercase. Identifiers are user-defined names for variables, functions and arrays.

2.4 Constants

KindRules / examples
IntegerDigits only, no decimal point, no spaces, commas or non-digits. Valid: 3543, -89022, 0, +58. Invalid: 23,487, $550, 3 333. Octal: leading 0 (044). Hexadecimal: 0x or 0X (0x450). 16-bit range: -32,768 to 32,767. Qualifiers: u, L, UL.
RealMust have a decimal point: 35.89, -0.987. Exponential form mantissa e exponent: 3.2e4, 4.8e-2, -43e+3.
CharacterOne character in single quotes: '4', 'A', '^'. Has an ASCII integer value. '4' is not the number 4.

Escape sequences: \a alert, \b backspace, \f form feed, \n new line, \r carriage return, \t tab, \v vertical tab, \? question mark, \\ backslash, \0 null.

2.5 Variables

Variable: a data name for a memory location. Its value can change during execution (a constant cannot).

Names: letters, digits, underscores; the first character must be a letter; no commas or blanks; not a keyword; case sensitive (sum ≠ SUM). Valid: Max_length, age, a1, T1.

2.6 Instructions and data types

Four kinds: type declaration, input/output, arithmetic, control. Primary types:

TypeDetails
intWhole numbers; usually 2 bytes; -32,768 to 32,767 (16-bit). The sixteenth bit is the sign (0 positive, 1 negative).
floatReal numbers; 4 bytes (32 bits); 6 digits of precision.
charOne character; 1 byte; signed -128 to 127; unsigned char 0 to 255.
doubleDouble-precision floating point.

Declaration: data_type v1, v2; e.g. int a; char first; float percent, avg;. Declare before use, usually at the top. Initialisation: int i = 10; and multiple assignment a = b = c = 1;.

Arithmetic instruction: variable = expression; – the variable is on the left and every operator must be written (p = q*r, not p = qr). Chars use ASCII values in arithmetic. ASCII: 0–9 = 48–57, A–Z = 65–90, a–z = 97–122.

2.8 Input, output and symbolic constants

printf("format", list): %d int, %f float, %c char. scanf("%f", &len); reads input; always put & before the variable; separate several values with white space.

Area of rectangle: len=4.5, breadth=2.8 → area = 12.599999 (printed with %f).
Two-digit sum: c=a/10; b=a%10; sum=c+b (83 → 11).
Symbolic constant: #define PI 3.14. Not a variable and not declared; usually uppercase; defined before use; no space between # and define; no semicolon; its type depends on its value.

Chapter 3 – Control Statements

Decision control: changing the order of execution depending on conditions, so one set of instructions runs in one situation and a different set in another. C's decision instructions: if, switch, the conditional operator and goto.

3.1 The if statement

The test condition goes in parentheses after if (usually with relational operators < <= > >= == !=). True: the statement(s) run. False: they are skipped. That is two-way branching.

if (test condition)
{
  statement block;
}
statement-a;
Several statements after if must be inside braces { }; without braces only the first statement belongs to the if. After the block, statement-a always runs.
Even number: if (num % 2 == 0) { printf("The number is even"); }. Input 20 prints the message; input 3 skips it.

3.2 if-else

if (test condition) { if block } else { else block }
statement-a;

Exactly one block runs (if block or else block), then control goes to statement-a. Example: if (marks >= 40) pass else fail; if (num % 2 == 0) even else odd.

3.3 Nested if-else

An if-else placed inside an if or else block; there is no limit to nesting. If condition 1 is true, condition 2 is tested (block-1 or block-2); if condition 1 is false, block-3 runs.

Marks: if (marks < 75) { if (marks >= 60) first class else second class } else distinction.
Characters: isalpha(ch1) and isdigit(ch1) need #include <ctype.h>; getchar() reads a character.

3.4 The if-else ladder

if (condition_1) statement_1;
else if (condition_2) statement_2;
else if (condition_3) statement_3;
else default;
statement-a;

Used for multipath decisions. Conditions are tested top-down; at the first true one its block runs and control leaves the ladder. If all are false, the final else (default) runs. Many nested levels become hard to read and debug.

3.5 Logical operators with if

&& (AND), || (OR), ! (NOT) join conditions and avoid long nests. Grades: if ((per>=50) && (per<60)) printf("Second Class"); with First >= 60, Second 50–59, Pass 40–49, Fail < 40. Greatest of three: if ((a>b) && (a>c)) a; else if ((b>a) && (b>c)) b; else c (100, 150, 5 gives b).

Priority (high to low)Operators

3.6 The switch statement

switch (integer expression)
{
  case constant-1: statement block-1; break;
  case constant-2: statement block-2; break;
  default: default block; break;
}
statement-a;
  • The expression must give an integer value; each case constant (integer or character) must be different.
  • The expression is matched with each case in turn; break leaves the switch.
  • default is optional and runs when nothing matches.
  • Cases with several statements need no braces.
Without break the program runs the matched case AND all following cases and the default (fall-through). The menu example uses this on purpose: case 'F': case 'f': ... so both letter cases work.
Grade codes: 1 Distinction, 2 First Class, 3 Second Class, 4 Fail, default "Result Declared"; input 4 prints Fail. Switch is often used for menu selection.

3.7 The conditional operator

Listed in the chapter contents; the form is exp1 ? exp2 : exp3 (see Chapter 2).

3.8 The goto statement

goto label;
 ...
label:
  statement-1;

Unconditional jump. The label is any valid variable name followed by a colon where control lands; it may be before or after the goto. exit ends the program. An unconditional goto loop (e.g. read x, square it, goto again) never ends.

Avoid goto: programs become unreadable and hard to debug; if, for, while and switch can replace it.
PDF slips: the grade ladder prints ranges overlapping at 50 and 60 (use >= 60, >= 50, >= 40 in order); the pass program says "greater than 40" but tests >= 40.

Chapter 4 – Loops

Loop: executes statements repeatedly until a condition is met, or a set number of times (variable loop and fixed loop). A loop has two segments: the body and the control statement that checks the condition.
Entry controlledExit controlled
Test first, then body. May run zero times. while and for.Body first, then test. Runs at least once. do-while.
A wrong test condition gives an infinite loop: the control never leaves the loop.

4.1 while

while (test condition)
{
  body of the loop;
}

Steps: initialise the counter, check the condition, execute the body, increment the counter and check again. Braces are needed for more than one statement. Counters can also decrement, and can be real. The condition must become false at some point.

Sum of first ten numbers: sum=0; i=1; while(i<=10){ sum=sum+i; i++; } prints 55. Counting down: i=10; while(i>=1){sum=sum+i; i=i-1;} also gives 55.
Infinite loop example: setting i = 1 inside the body resets the counter each time, so i<=10 is always true.

Odd loop (variable loop): repeats while the user answers 'Y' (while(ans=='Y') with getche()); the count is not known in advance. Loop tests can use && and ||, e.g. while((i<=10)&&(a>b)).

4.2 do-while

do
{
  body of the loop;
}
while (test condition);

Only difference from while: the body runs once before the first test. Note the semicolon after the condition. Example: product of 1 to 10 (prod=1, i=1; prod=prod*i; i++ while i<=10) = 3628800.

4.3 Nested while

The inner loop runs fully for each outer pass. Five outer passes × five inner passes print five rows of *****.

4.4 for

for (initialisation; test-condition; increment)
{
  body of the loop;
}

Initialisation (i = 1) runs once; the test is checked before each pass; the increment runs after each pass. Semicolons separate the parts; no semicolon after the increment or after the closing parenthesis. for(i=1;i<=5;i++) prints 1 to 5.

  • May decrement the counter
  • Sections can be omitted but the semicolons stay: for(;i<=10;). No test condition = infinite loop
  • Several initialisations or increments separated by commas: for(k=1,i=1; ...; i++, p=p+1)
  • for(i=0; ++i<=10;) increments and compares together
  • The test may be compound: i<=10 && sum<100

4.5 Nested for

for(i=1;i<=5;i++)
{
  for(j=1;j<=5;j++)
  { printf("*"); }
  printf("\n");
}

j restarts at 1 for every i; printf("\n") ends each row.

4.6 break and continue

breakcontinue
Exits the loop at once; control goes to the statement after the loop. Also ends a case in switch.Skips the rest of the body and starts the next iteration. In for, the counter is incremented, then the test is checked; in while/do-while the test is checked.
continue: read numbers until 0; if(num%2==0) continue; skips even numbers, so only odd numbers are printed.
PDF slips: the book writes i = i ++; (use i++; or i = i + 1;) and a stray ; after while(...) in the getchar example, which would make an empty loop.

Chapter 5 – C++ Programming Language

5.1 Object-oriented ideas

A C++ program is a collection of objects that communicate by calling each other's methods.

TermMeaning
ObjectHas states and behaviours (a dog: colour, name, breed; wagging, barking). An instance of a class.
ClassA template or blueprint describing the states and behaviours of its objects.
MethodA behaviour; where logic is written and data manipulated.
Instance variablesEach object's own variables; their values make the object's state.

5.2 Program structure

#include <iostream>
using namespace std;
// main() is where program execution begins.
int main()
{
  cout << "Hello World";   // prints Hello World
  return 0;
}
  • Header <iostream> is needed for cout.
  • using namespace std; tells the compiler to use the std namespace.
  • // single-line comment; /* */ multi-line comment.
  • int main() is where execution begins; cout << displays output; endl (manipulator) ends a line; return 0; ends main and returns 0.
Exercise 1: print "Oh what / a happy day! / Oh yes, / what a happy day!" using separate cout << "..." << endl; lines.

Standard C++ has 74 keywords (and, asm, auto, bool, break, case, catch, char, class, const, continue, default, delete, do, double, else, enum, extern, float, for, friend, goto, if, inline, int, long, namespace, new, private, protected, public, return, short, signed, sizeof, static, struct, switch, template, this, throw, true, try, typedef, union, unsigned, virtual, void, volatile, wchar_t, while ... and more). Keywords are reserved.

5.4 Variables and literals

Local variables are declared inside a function or block and are usable only there. Global variables are declared outside functions and can be used by any function throughout the program. Example: int a, b, c; a=10; b=20; c=a+b; cout << c; prints 30.

Character literals use single quotes: 'x', escape sequences such as '\t' and '\n'. A literal starting with L (uppercase) such as L'x' is a wide character stored in wchar_t. Example: cout << "Hello\tWorld\n\n";

5.5 Operators

Arithmetic, relational, logical, bitwise, assignment and misc operators. With A = 10 and B = 20: A+B = 30, A-B = -10, A*B = 200, B/A = 2, B%A = 0, A++ gives 11, A-- gives 9. With m=54, n=20: m+n=74, m-n=34, m*n=1080, m/n=2, m%n=14.

  • ++i: increment first, then use the value. i++: use the original value, then increment. Cannot be used on constants.
  • Compound assignment: x += y; x *= y; x /= y;
  • Math functions (include <cmath>): sin, cos, tan, atan, cosh, sqrt, pow, exp, log, log10. pow(2.5, 3.0) = 15.625. pow(x+3.0) is an error: pow needs two arguments.
  • A function call is an expression whose value is the return value: y = pow(x, 3.0);

5.6 Control statements and loops

  • while repeats while the condition is true. for: init runs once; condition tested; body; increment; repeat. do...while tests at the bottom, so it runs at least once: do { cout << a; a = a + 1; } while (a < 20);
  • break ends the loop (the innermost one in nested loops) and ends a switch case. continue forces the next iteration.
  • goto jumps to a label in the same function; highly discouraged because control flow is hard to trace.
  • Infinite loop: a loop whose condition never becomes false, e.g. for(;;).
  • if...else if...else: an if has zero or one else, which comes last; any number of else-ifs come before it; once one succeeds the rest are not tested.
  • switch: expression must be integral or enumerated; constants must match its type; execution runs until a break (fall-through otherwise); default is optional and last.

5.7 Arrays

An array stores a fixed-size sequence of elements of the same type in contiguous memory; elements are reached by index starting at 0.

double balance[10];                          // declare
double balance[5] = {1000.0, 2.0, 3.4, 17.0, 50.0};
double balance[] = {1000.0, 2.0, 3.4, 17.0, 50.0}; // same
balance[4] = 50.0;
double salary = balance[9];   // 10th element
  • Values in braces cannot outnumber the declared size.
  • char arrays hold strings ended by '\0': char name[] = "Hugo"; uses 5 bytes. A char array of 40 holds 39 characters plus '\0'.
  • C strings cannot be assigned or compared with = or ==; use strcpy(str1, str2), strlen(), strcmp().
  • Two-dimensional array: float number[3][10]; is 3 rows × 10 columns (30 elements); number[0][9] = 7.2; is row 0, column 9. Only the first size may be omitted: int arr[][3] = {{5},{7}};
